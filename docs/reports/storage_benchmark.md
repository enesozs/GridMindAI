# Storage dispatch on residual load: benchmark

_Generated by `gridmind storage`._

A stylised storage fleet (2 GW / 8 GWh, 90% round-trip efficiency, state of charge 10%–90%, starting and ending each day at 50%) is scheduled day-ahead to minimise the daily peak of residual load (load − wind − solar). Each schedule is planned on a forecast and then applied to the realised residual load. Value is measured as peak reduction, not revenue: this project uses no price data.

Test year 2025-11-01 → 2026-10-31: 364 days evaluated, 1 skipped because a forecast or the actual was incomplete.
